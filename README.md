# Multi-Stop Route Planner (CSE476 CA1 Project 1 — Topic T14)

An agent that takes a list of places you want to visit and works out
a sensible order to visit them in.

- `backend/` — FastAPI service wrapping a Groq-powered plan-act agent
- `frontend/` — React UI to chat with the agent and see its tool-call
  trace live

Status: work in progress, built commit by commit. Full README (tools,
memory, honest failure) will be written once the agent is complete.
